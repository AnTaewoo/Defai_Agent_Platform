D.A.P · 유즈케이스 맵

프로젝트 단위로 격리된 멀티에이전트 RAG + 에이전틱 문서·코드 생성 플랫폼. 모든 요청은 3중 게이트를 통과한다.

설계 일관성 검토 완료 모순 12곳 정리 전 모듈 컴파일 페이즈 P1–P12 온프레미스 · 망분리

01 핵심 접근 불변식

검색·에이전트·도구·생성 등 보안 민감 호출은 모두 SessionContext를 받고, 아래 세 게이트를 AND로 통과한다.

GATE ①
프로젝트 격리
project_id == 활성 프로젝트. 멤버 아니면 거부.
GATE ②
등급 클리어런스
security_level ≤ level. 부서 무관(프로젝트 멤버면 접근).
GATE ③
에이전트 가용
프로젝트 보유 ∩ {등급 ≤ level}. 수동 부여 없음.

04 라이프사이클 · 모델 → 에이전트 → 세션

에이전트 등급은 서빙 모델 등급에서 자동으로 흐른다. 어느 단계에서도 자기 등급 위로 못 올라간다.

model serving → agent onboarding → in-session pick
sequenceDiagram
  autonumber

  actor PA as project_admin
  participant P as projects
  actor U as 사내 직원
  participant S as sessions
  ML->>V: 오픈웨이트 모델 서빙 + 보안등급 지정
  Note over V: agent.security_level = 모델 등급 (자동)
  PA->>P: add_project_agent(ctx, agent)
  Note right of P: 게이트 ⓐ 등급 ≤ 생성자.level
게이트 ⓑ role=project_admin
  U->>S: open_session(principal, project)
  S->>P: membership 확인 (멤버 아니면 거부)
  U->>S: select_agent(ctx, agent_id)
  Note right of S: available_agents = 프로젝트 보유 ∩ {등급 ≤ level}

  S-->>U: active_agent_id 설정된 세션

05 RAG 질의 · 3중 게이트

권한은 후처리가 아니라 OpenSearch 쿼리 filter에 질의 전 강제 주입된다.

query → pre-filtered hybrid search → grounded answer
sequenceDiagram
  autonumber
  actor U as 사내 직원
  participant API as FastAPI
  participant SE as search(ctx)
  participant OS as OpenSearch
  participant AG as agent (LangGraph)
  participant V as vLLM
  U->>API: 질의 (세션 ctx)
  API->>SE: search(query, ctx=SessionContext)
  SE->>OS: filter[ project_id, level≤ ] + BM25 + kNN
  OS-->>SE: 허용 청크만 (RRF 결합)
  SE-->>AG: 근거 청크 + 출처
  AG->>V: 등급 라우팅된 엔드포인트로 생성
  V-->>AG: 스트리밍 토큰
  AG-->>U: 답변 + 출처(Citation) + 감사 로그

06 에이전틱 생성 · 등급 전파 & 샌드박스

생성물 등급 = 접한 모든 소스의 max. 코드 실행은 망 차단 샌드박스에서만.

workflow plan→act→observe · docgen · codegen(sandbox)
sequenceDiagram
  autonumber
  actor U as 사내 직원
  participant W as workflows(ctx)
  participant T as tools
  participant SE as search
  participant DG as docgen
  participant CG as codegen
  participant SB as sandbox (egress 0)
  participant ST as 프로젝트 스토리지(MinIO)
  U->>W: 과제 (ctx)
  loop plan → act → observe (max_steps)
    W->>T: available_tools(ctx) 중 선택
    T->>SE: 근거 검색 (3중 게이트)
    SE-->>W: 청크 (+running_level 갱신)
  end
  alt 문서 생성
    W->>DG: generate_document(ctx)
    DG-->>ST: Artifact(level=max, 출처·분류 표기)
  else 코드 생성/실행
    W->>CG: generate_code(ctx)
    CG->>SB: run_in_sandbox (외부 스토어 직접접근 0)
    SB-->>CG: 결과 (세션 등급 상속)
  end
  W-->>U: Artifact (등급 전파됨)
