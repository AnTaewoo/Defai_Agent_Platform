# D6. 총괄시험 계획서 — D.A.P

문서정보: D.A.P · 설계 · D6

## 1. 시험 전략
| 수준 | 범위 | 도구 |
|---|---|---|
| 단위(D11) | 모듈 함수·불변식 | pytest |
| 통합(D10) | 모듈 파이프라인 | pytest |
| 시스템(D7) | 엔드투엔드 + 보안 | pytest/e2e |
| 인수 | 고객 시나리오 | 수동/UAT |

## 2. 중점(보안) 시험
- 게이트 ①프로젝트 ②등급 pre-filter + ③에이전트 가용 — 우회 경로 0 (부서는 게이트 아님)
- 등급 전파(propagate_level): 생성물 등급 = 소스 max
- 샌드박스 egress 0, 외부 스토어 직접접근 0
- 외부 클라우드 LLM 호출 0건
- 미허용 에이전트 가용/선택 0건(등급 위)

## 3. 환경/추적성
infra(docker-compose)로 OpenSearch/Postgres/MinIO/vLLM(옵션) 기동. 요구사항 추적표(R3) 연계.
